Entry for the make.fun bounty **Funniest Cat Voicemail Greeting**
($2, winner takes all). `main.ts` writes one voicemail greeting recorded
by a cat to `/output/entry.txt`:

> You've reached Pickles. It's 4 a.m. and I'm screaming for food. Leave a message, I'll knock it off the shelf.

109 characters, no trailing newline. Ten candidates were scored 1–5 against
each of the five judge criteria; this line scored highest (23/25) — a cat
called Pickles, the 4 a.m. food scream, and the knock-it-off-the-shelf punch
landing last.

Run it with Node 22:

```sh
node main.ts
```
